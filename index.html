Локальные файлы

В папке laba2 находятся необходимые файлы: file.tar.gz, image.png, index.php, скриншоты и др.

Скриншот 0.1: Содержимое локальной папки

Инициализация Git и отправка на GitHub

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/MinhThuTanya/web-hw2.git
git push -u origin main

Локальный репозиторий создан, все файлы добавлены, выполнена отправка на GitHub.

Скриншот 0.2: Отправка файлов на GitHub

Клонирование репозитория на сервер

git clone git@github.com:MinhThuTanya/web-hw2.git
mkdir -p ~/www/hw2
cp -r ~/web-hw2/* ~/www/hw2/

Репозиторий склонирован в домашнюю директорию, файлы скопированы в веб-доступный каталог ~/www/hw2.

Скриншот 0.6: Окно PuTTY ожидает запрос

Пункт 1. Получить главную страницу методом GET в протоколе HTTP/1.0

GET / HTTP/1.0
Host: u82323.kubsu-dev.ru

Запрос корневой директории сайта. В корне находится index.php, который возвращает вывод (ошибка подключения к БД не влияет на успешность).

Результат (скриншот 1.png):

  • Статус: HTTP/1.1 200 OK
  • Заголовки: Server: Apache/2.4.58 (Ubuntu), Content-Length: 335, Content-Type: text/html; charset=UTF-8
  • Тело: сообщение "PHP is working!" и ошибка БД
Скриншот 1: GET / HTTP/1.0

Пункт 2. Получить внутреннюю страницу методом GET в протоколе HTTP/1.1

GET /hw2/index.php HTTP/1.1
Host: u82323.kubsu-dev.ru
Connection: close

Запрос файла index.php из каталога /hw2/. Скрипт возвращает статус 404, но выполняет код и выводит данные.

Результат (скриншот 2.png):

  • Статус: HTTP/1.1 404 Not Found задан в файле
  • Заголовок Content-Type: text/html; charset=UTF-8
  • Тело: Array ( ) Привет, мир!

Статус 404 (прописанный в файле) не мешает анализу содержимого.

Скриншот 2: GET /hw2/index.php

Пункт 3. Определить размер файла file.tar.gz, не скачивая его

HEAD /hw2/file.tar.gz HTTP/1.1
Host: u82323.kubsu-dev.ru
Connection: close

Метод HEAD возвращает только заголовки. Позволяет узнать размер файла из поля Content-Length.

Результат (скриншот 3.png):

  • Статус: HTTP/1.1 200 OK
  • Заголовок Content-Length: 11335 – размер в байтах
  • Тип файла: Content-Type: application/x-gzip
Скриншот 3: HEAD /hw2/file.tar.gz

Пункт 4. Определить медиатип ресурса /image.png

HEAD /hw2/image.png HTTP/1.1
Host: u82323.kubsu-dev.ru
Connection: close

Аналогично пункту 3, определяем MIME-тип изображения.

Результат (скриншот 4.png):

  • Статус: HTTP/1.1 200 OK
  • Заголовок Content-Type: image/png
  • Размер: Content-Length: 10506 байт
Скриншот 4: HEAD /hw2/image.png

Пункт 5. Отправить комментарий на сервер по адресу /index.php (POST)

POST /hw2/index.php HTTP/1.1
Host: u82323.kubsu-dev.ru
Content-Type: application/x-www-form-urlencoded
Content-Length: 14
Connection: close

comment=Hello

Тело запроса: comment=Hello (длина 14 байт).

Отправка POST-данных (имитация формы). Скрипт возвращает статус 404, но выводит содержимое массива $_POST.

Результат (скриншот 5.png):

  • Статус: HTTP/1.1 404 Not Found
  • Тело: Array ( [comment] => Hello ) Привет, мир!
Скриншот 5: POST /hw2/index.php

Пункт 6. Получить первые 100 байт файла /file.tar.gz

GET /hw2/file.tar.gz HTTP/1.1
Host: u82323.kubsu-dev.ru
Range: bytes=0-99
Connection: close

Заголовок Range запрашивает только указанный диапазон байт – первые 100 байт архива.

Результат (скриншот 6.png):

  • Статус: HTTP/1.1 206 Partial Content
  • Заголовок Content-Range: bytes 0-99/11335
  • Content-Length: 100
  • Тело содержит бинарные данные (первые 100 байт файла)
Скриншот 6: GET /hw2/file.tar.gz с Range

Пункт 7. Определить кодировку ресурса /index.php

HEAD /hw2/index.php HTTP/1.1
Host: u82323.kubsu-dev.ru
Connection: close

Запрос HEAD для получения заголовков. Кодировка указана в поле Content-Type.

Результат (скриншот 7.png):

  • Статус: HTTP/1.1 404 Not Found
  • Заголовок Content-Type: text/html; charset=UTF-8 – кодировка UTF-8
Скриншот 7: HEAD /hw2/index.php
